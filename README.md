# AI Student Shopping Agent

## Problem Statement

Students often struggle to find products within their budget while comparing multiple options.

## Solution

An AI-powered shopping assistant that understands user requirements, recommends products, compares alternatives, and simulates checkout.

## Features

- Product Search
- Budget Filtering
- Product Comparison
- AI Recommendations (Gemini)
- Product Images
- Checkout Simulation
- Order Summary
